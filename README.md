# Momentum v7.13

일정과 습관을 한곳에서 관리하고, 진행률과 통계를 확인할 수 있는 개인 일정 관리 웹앱입니다.

## 주요 기능

- 월간 / 주간 / 하루 캘린더
- 일정 및 반복 일정 관리
- 일정별 체크리스트
- 습관 등록 및 반복 관리
- 습관 HEATMAP
- 일정·습관 진행률 기록
- 날짜별 / 월별 통계
- 카테고리별 성취도
- 습관별 달성률
- 모바일 / PC 반응형 화면
- 검색 기능

## v6.9 변경사항

- 체크리스트 통계에서 지난 일정의 미완료 항목을 실패로 집계
- 월간 캘린더에서 날짜 클릭 시 하루 일정 화면으로 이동하는 기능 제거
- 월간 캘린더의 일정 제목 표시 제거
- 월간 캘린더 날짜 칸에 해당 날짜의 일정 + 습관 종합 달성률 표시
- 모바일 통계 상단을 2열 × 2행으로 정리
- 모바일 통계 제목을 짧게 표시하도록 개선
- 30분 일정의 글자 크기와 세로 위치 미세 조정

## 프로젝트

**Momentum**

개인 일정, 습관, 체크리스트와 달성률을 한 화면에서 관리하기 위해 제작한 웹앱입니다.


## v6.11 변경사항

- HEATMAP에서 해당 표시 기간 전에 이미 종료된 습관을 숨김
- HEATMAP에서 해당 표시 기간 이후에 시작하는 습관도 숨김
- 표시 기간과 습관의 시작일·종료일이 실제로 겹치고, 반복 대상 날짜가 존재할 때만 습관 표시
- 해당 기간에 표시할 습관이 없으면 `이 기간에는 습관이 없습니다.` 안내만 표시


## v7.0 화면 구조 개편

- 캘린더를 `SELECTED DAY / 주간` 구조로 변경
- SELECTED DAY에 빠른 일정 입력 이동
- 주간에서는 빠른 입력을 제거하고 카테고리 필터/수정 기능에 집중
- 하루 일정 화면은 주간 캘린더에서만 접근하는 기존 흐름 유지
- 통계 화면에 월간 성과 캘린더 통합
- 월간 날짜를 누르면 해당 날짜의 `DAY INSIGHT` 표시
- DAY INSIGHT에서 종합·일정·습관·체크리스트 성과 확인
- 기존 최근 7일 / 월 요약 / 카테고리 / 습관 통계를 월간 캘린더 아래에 유지
- 30분·1시간처럼 작은 하루 일정은 체크리스트를 `완료/전체`로 압축 표시
- 압축 체크리스트를 누르면 전체 체크리스트 팝업에서 바로 상태 변경 가능

## v7.1 변경사항
- SELECTED DAY / 주간에서 잘못 나타나던 월간 캘린더 완전 제거
- 월간 캘린더는 통계 화면 전용으로 분리
- 통계 월간 캘린더를 월요일 시작 / 일요일 끝으로 변경
- SELECTED DAY 헤더 압축
- SELECTED DAY 일정 시작/종료 시간 2줄 표시
- 빠른 입력 성공 메시지 제거
- PC HEATMAP 31일을 3줄 안에 배치
- DAY INSIGHT를 별도 카드가 아닌 선택 날짜 셀 내부에 표시


## v7.2 변경사항
- 월간 캘린더의 기본 날짜 칸 높이를 축소
- 선택 날짜도 셀 높이가 커지지 않도록 변경
- DAY INSIGHT를 엑셀 메모처럼 작은 플로팅 창으로 표시
- 플로팅 DAY INSIGHT는 선택한 날짜 옆에 자동 배치되고 달력 크기에 영향을 주지 않음
- SELECTED DAY 빠른 입력 바의 높이와 여백을 축소


## v7.4 변경사항
- v7.3에서 깨진 화면 DOM 구조를 v7.2 기준으로 복구
- 캘린더 / 습관 / 통계 / 검색 화면이 다시 정상 표시되도록 복원
- 카테고리 필터와 `카테고리 관리` 버튼을 주간 캘린더 내부에 안전하게 배치
- 카테고리 추가 / 이름 수정 / 색상 수정 / 삭제 기능은 기존 관리창 유지


## v7.5 변경사항
- 월간 캘린더에서 날짜 선택 시 표시되는 DAY INSIGHT 팝업의 방향 화살표(말풍선 삼각형) 제거
- 팝업 위치와 내용은 그대로 유지


## v7.6 변경사항
- 주간 캘린더의 카테고리 필터 / 카테고리 관리가 렌더링 후 사라지는 문제 수정
- 카테고리 관리 UI를 주간 캘린더 바로 위의 고정 영역으로 이동
- SELECTED DAY 빠른 일정 바 외곽 테두리 제거 및 전체 높이 추가 축소
- 모바일 주간 캘린더의 세로 표시 영역을 하단 내비게이션 위까지 확대
- DAY INSIGHT 팝업의 실제 화살표 pseudo-element 완전 제거


## v7.7 변경사항
- 렌더링 경로 최적화: 현재 화면에 필요한 UI만 갱신하도록 정리
- 주간 상단 툴바에 `카테고리 관리` 버튼을 직접 추가해 항상 접근 가능하도록 개선
- 통계 진입 시 DAY INSIGHT 자동 팝업 제거, 월간 날짜 클릭 시에만 표시
- SELECTED DAY의 DAY PROGRESS / MONTH SUMMARY 제거 후 DAY INSIGHT로 통합
- 통계의 `100% 달성 습관 기록` 항목 및 계산 제거
- 기본 7일 주간 보기에서 좌우 스와이프로 이전 주 / 다음 주 이동 복구


## v7.8 긴급 수정
- 일정 추가/수정 시간 입력을 안정적인 기본 time input으로 복구
- 깨진 커스텀 시간 휠 및 자동 날짜 선택 레이어 비활성화
- 모바일 일정 추가/수정 전에 불필요한 선택 화면이 나타나는 문제 제거
- 빠른 입력 시간 파싱 개선: `19:00에`, `19시 30분`, `오후 7시 30분` 등 지원
- 일정 드래그 이동 후 로컬 화면 즉시 갱신
- 모바일 일정 이동 롱프레스 감도 개선
- 중복 주간 스와이프 핸들러 제거해 일정 이동과의 충돌 완화


## v7.9 변경사항
- 빠른 입력에 시작시간-종료시간 범위 입력 지원
- `19-22시 가족모임`, `19:00-22:30 공부`, `19시부터 22시 회의` 형식 인식
- `오후 7-10시 모임`, `오전 9시-오후 1시 일정` 형식도 인식
- 시간 범위가 입력되면 시작/종료 시간을 그대로 저장
- 시간 범위가 없으면 기존처럼 시작 시간 + 기본 1시간으로 저장


## v7.10 긴급 로딩 복구
- Firebase 인증 persistence 설정 실패 시에도 앱 초기화 계속
- 인증 오류 시 무한 로딩 대신 로그인 화면과 오류 안내 표시
- 10~12초 이상 초기화 지연 시 로딩 화면 자동 해제
- v7.9 빠른 입력 시작시간-종료시간 범위 기능 유지


## v7.11 로그인 복구
- Google 팝업 로그인이 성공하면 `onAuthStateChanged` 응답만 기다리지 않고 반환된 사용자 정보로 즉시 앱 진입
- 로그인 직후 캘린더 렌더링 및 Firebase 데이터 리스너 연결
- 자동 로그인 확인이 늦을 때도 Google 로그인 버튼을 정상적으로 사용할 수 있도록 안내 수정


## v7.12 긴급 수정
- `Cannot access 'startupWatchdog' before initialization` 오류 수정
- `startupWatchdog`를 앱 초기화 초기에 선언하고 이후 타이머를 할당하도록 변경
- 로그인 성공 / 인증 상태 확인 / 인증 오류 시 watchdog 타이머를 안전하게 정리


## v7.13 안정화 / 최적화
- 로그인 persistence를 초기 화면과 병렬로 준비해 브라우저 진입 속도 개선
- Google 로그인 처리와 Firebase 데이터 연결 경로를 `onAuthStateChanged` 한 곳으로 통합
- 로그인 후 재접속 시 자동 로그인 유지
- Firebase snapshot 연속 렌더링을 한 프레임으로 합쳐 초기 로딩 부담 감소
- 빠른 입력을 서버 snapshot과 무관하게 즉시 화면에 반영
- 일정 이동의 중복 렌더 제거 및 주간 스크롤 위치 유지
- 이동 대상 날짜 전체의 초록 강조 삭제, 일정 위치 네모 미리보기만 유지
- 일정 추가/수정 시간 선택을 24시간제 커스텀 창으로 변경
- 시간 입력칸 어디를 눌러도 바로 시간 선택창 표시
- 사용하지 않는 legacy 시간 UI는 숨김 처리
