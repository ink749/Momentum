# Momentum v6.11

일정과 습관을 한곳에서 관리하고, 진행률과 통계를 확인할 수 있는 개인 일정 관리 웹앱입니다.

## 주요 기능

- 월간 / 주간 / 하루 캘린더
- 일정 및 반복 일정 관리
- 일정별 체크리스트
- 습관 등록 및 반복 관리
- 습관 HEATMAP
- 일정·습관 진행률 기록
- 날짜별 / 월별 통계
- 카테고리별 성취도
- 습관별 달성률
- 모바일 / PC 반응형 화면
- 검색 기능

## v6.9 변경사항

- 체크리스트 통계에서 지난 일정의 미완료 항목을 실패로 집계
- 월간 캘린더에서 날짜 클릭 시 하루 일정 화면으로 이동하는 기능 제거
- 월간 캘린더의 일정 제목 표시 제거
- 월간 캘린더 날짜 칸에 해당 날짜의 일정 + 습관 종합 달성률 표시
- 모바일 통계 상단을 2열 × 2행으로 정리
- 모바일 통계 제목을 짧게 표시하도록 개선
- 30분 일정의 글자 크기와 세로 위치 미세 조정

## 파일 구성

- `index.html` — 화면 구조
- `style.css` — 디자인 및 반응형 스타일
- `script.js` — 캘린더, 일정, 습관, 통계 등 주요 기능
- `README.md` — 프로젝트 설명

## GitHub Pages 배포

저장소의 루트에 위 파일들을 업로드한 뒤 GitHub Pages를 설정합니다.

**Settings → Pages → Build and deployment**

- Source: `Deploy from a branch`
- Branch: `main`
- Folder: `/(root)`

저장 후 Pages 배포가 완료되면 웹에서 사용할 수 있습니다.

## 프로젝트

**Momentum**

개인 일정, 습관, 체크리스트와 달성률을 한 화면에서 관리하기 위해 제작한 웹앱입니다.


## v6.11 변경사항

- HEATMAP에서 해당 표시 기간 전에 이미 종료된 습관을 숨김
- HEATMAP에서 해당 표시 기간 이후에 시작하는 습관도 숨김
- 표시 기간과 습관의 시작일·종료일이 실제로 겹치고, 반복 대상 날짜가 존재할 때만 습관 표시
- 해당 기간에 표시할 습관이 없으면 `이 기간에는 습관이 없습니다.` 안내만 표시
